## 📌 About the project

**Calculadora** is a web-based application designed to execute everyday mathematical calculations quickly and effortlessly. 

Featuring a modern dark interface, the application allows users to perform standard arithmetic operations, percentage calculations, and easy display edits using backspace and clear controls.

## 💻 Technologies

This project was built using core web technologies without external libraries or frameworks:

* **HTML5** - Layout structure and UI containers
* **CSS3** - Modern dark theme styling, Grid/Flexbox layout, custom rounded buttons, and interactive hover state effects
* **JavaScript (ES6+)** - Dynamic calculation execution, state management, display updates, and event listeners

---

## ⚙️ Features

- [x] **Standard Operations**: Addition (`+`), Subtraction (`-`), Multiplication (`X`), and Division (`/`)
- [x] **Percentage Engine**: Quick percentage calculations (`%`)
- [x] **Display Editing**: 
  - Clear button (`C`) to reset the calculation state
  - Backspace button (`←`) to delete the last entered digit
- [x] **Decimal Precision**: Full support for floating-point calculations using comma/decimal inputs
- [x] **Dark Theme Design**: Clean interface optimized for visual comfort
- [x] **Responsive Layout**: Formatted for smooth display on both desktop and mobile viewports

## 👷 Installation & How to Run

Since this project relies strictly on native browser execution, no package managers or build steps are needed.

### 1. Clone the repository
```bash
$ git clone [https://github.com/VineDevJunior/calculadora.git](https://github.com/VineDevJunior/calculadora.git)
```

### 2. Open the project
Navigate into the project folder and open index.html in your browser:
```bash
$ cd calculadora
```
Tip: If you use VS Code, you can open index.html using the Live Server extension for real-time updates.
